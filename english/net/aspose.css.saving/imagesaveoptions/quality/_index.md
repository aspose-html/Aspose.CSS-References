## ImageSaveOptions.Quality property

## Quality {#quality}

Lossy codec quality, 1 (smallest) to 100 (best). Default 100. Jpeg encodes at this quality; Webp is lossless at 100 and lossy below it; Png ignores it.

```csharp
public int Quality { get; set; }
```
