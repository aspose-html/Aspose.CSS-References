## ScriptingSettings.Enabled property

## Enabled {#enabled}

Whether document and user scripts run. Default false: scripts are not run and their count is reported as an Information diagnostic ScriptsDisabled. When set, the document's scripts run in document order, then [Configuration.UserScripts](../../configuration/userscripts/#userscripts), and the mutated document is laid out. Scripts reach no .NET type, make no network or file request except through [ResourceSettings](../../resourcesettings/), and stop at the budgets below. A script's error is reported as ScriptError and a budget reached as ScriptLimitExceeded; neither stops the conversion.

```csharp
public bool Enabled { get; set; }
```
