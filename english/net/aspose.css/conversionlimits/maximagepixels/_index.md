## ConversionLimits.MaxImagePixels property

## MaxImagePixels {#maximagepixels}

Pixels of one image or one output raster. Default 64,000,000: an ImageMode.FullContent PNG at a 1280 px viewport stops at about 50,000 px tall. Past it the save fails with LimitExceeded; raise this value, or save with ImageMode.PrintPages for one image per page.

```csharp
public long MaxImagePixels { get; set; }
```
