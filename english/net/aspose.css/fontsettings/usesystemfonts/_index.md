## FontSettings.UseSystemFonts property

## UseSystemFonts {#usesystemfonts}

Whether the machine's installed fonts are the last fallback: a character no configured and no bundled face maps takes an installed face that maps it. Family names never resolve to an installed face. Default true; false reads no installed font.

```csharp
public bool UseSystemFonts { get; set; }
```
