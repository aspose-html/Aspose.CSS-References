# Aspose.CSS-References

This repository contains the Aspose.CSS API references for https://reference.aspose.com/css/.

The pages under `english/` are generated from the shipped Aspose.CSS for .NET assembly and its XML documentation by the
Aspose.CSS release engine, and pushed here on each release: `main` builds the staging site, `production` builds
reference.aspose.com.
